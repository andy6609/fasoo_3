# TLS intercept policy for Local DLP proxy
#
# Supported formats:
#   <target> <action> [reason]
#   <process> <target> <action> [reason]
#   DEFAULT <action> [reason]
#
# process examples:
#   chrome.exe
#   devenv.exe
#   msedgewebview2.exe
#   *.exe
#   *
#
# target examples:
#   demo.local:9443
#   chatgpt.com:443
#   *.openai.com:443
#   *:443
#   *
#
# action values:
#   MITM    = decrypt HTTPS, inspect request/response body with DLP
#   BYPASS  = raw encrypted tunnel, metadata/audit only
#   AUDIT   = raw encrypted tunnel, but explicit security audit policy decision
#   IGNORE  = raw encrypted tunnel with noise-suppressed tunnel logs and summaries
#   BLOCK   = deny CONNECT before upstream connection
#
# Rules are evaluated from top to bottom. First match wins.
# Process-specific rules should be placed before broad wildcard rules.

# Local browser test targets. These match any process.
demo.local:9443 MITM local_browser_test
127.0.0.1:9443 MITM loopback_tls_test
localhost:9443 MITM localhost_tls_test

# Public, non-authenticated endpoints used by the automated real-site smoke tests.
# Restrict MITM to curl so normal browser traffic to these sites remains untouched.
curl.exe httpbin.org:443 MITM public_https_smoke_test
python.exe httpbin.org:443 MITM public_https_smoke_test
